Auxiliary repository containing materials related to the metadata of ESWC 2026 Main Track papers, supporting the comparison available in ORKG.

The ORKG comparison is available at: https://doi.org/10.48366/R1912668.

The repository contains:
- A CSV file with metadata extracted using LLMs from the abstracts of ESWC 2026 Main Track papers and manually corrected based on the authors’ feedback.
- Visualizations providing an overview of metadata statistics for the ESWC 2026 Main Track papers, which are also included in the ORKG comparison.
